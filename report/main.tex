\section*{Introduction}
\textbf{Task.} This project builds a real-time hand gesture recognition pipeline that detects a hand in webcam frames and classifies it into five discrete gestures (thumbs up, thumbs down, peace, open palm, or no hand). The goal is to deliver a lightweight end-to-end system that can be trained on a small custom dataset and run interactively.

\textbf{Motivation and problem statement.} Hand gestures are a natural, device-free interface for HCI, but reliable recognition must handle varying backgrounds, lighting, and hand sizes while keeping latency low. The problem we address is: given a live RGB stream, automatically localize the hand and predict the gesture class with high accuracy and stable real-time performance, following evaluation practices used in interactive graphics pipelines \cite{lighthouse_timer}.

\textbf{Own solution and results.} We combine MediaPipe-based hand detection to crop the region of interest with a compact CNN trained on our collected dataset, plus augmentation to improve robustness. The system reaches consistent classification on the five gestures and supports a live demo; detailed quantitative results and a confusion matrix are reported in the Results section.

\textbf{Contributions.} Tim Dedie implemented the data collection pipeline and augmentation experiments; Nick Somitsch implemented the CNN, training/evaluation scripts, and the live demo.

\section*{Background}
\textbf{Hand detection and preprocessing.} We use MediaPipe Hands to localize the hand via landmark-based detection and derive a bounding box for cropping. The cropped region is resized to $64 \times 64$ RGB and normalized, which reduces background clutter and gives a consistent input scale for the classifier.

\textbf{CNN-based classification.} Convolutional layers learn local edge and texture patterns, ReLU introduces non-linearity, and max-pooling builds spatial invariance. The final fully connected layers map the features to five gesture classes using a softmax output. The prediction and training objective are:
\begin{align}
    p_i = \frac{\exp(z_i)}{\sum_j \exp(z_j)}, \quad
    \mathcal{L} = -\sum_i y_i \log p_i
\end{align}
where $z_i$ are logits, $p_i$ the class probabilities, and $y_i$ one-hot labels.

\textbf{Data augmentation.} Random flips, rotations, brightness changes, blur, color jitter, and zoom improve robustness to viewpoint and illumination changes by exposing the network to plausible variations during training.

\section*{Method}
\textbf{Pipeline overview.} Each frame from the webcam is processed by MediaPipe Hands to detect landmarks and a bounding box; we crop the hand region with padding, resize to $64 \times 64$, and normalize. The cropped images are stored per class and later loaded by a custom dataset class that performs stratified train/test splitting.

\textbf{Model and training.} The classifier is a compact CNN with three convolutional blocks (Conv--ReLU--MaxPool), followed by a 256-unit fully connected layer and dropout before the final 5-way softmax. We train with cross-entropy loss using mini-batches and evaluate several augmentation settings (flip, rotation, brightness, blur, color jitter, zoom) as well as different dataset sizes to assess robustness.

\textbf{Evaluation and demo.} After training, we compute accuracy, F1-score, and a confusion matrix on the held-out test set. The best-performing model is used in a live demo that overlays the predicted class and confidence on the webcam stream. Figure~\ref{fig:blur_pipeline} summarizes the processing flow.
